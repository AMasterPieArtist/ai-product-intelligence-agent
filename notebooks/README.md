# Notebook 入口

先阅读[运行指南](../docs/getting_started.md)，在 VS Code 选择安装了项目依赖的 Python 内核。

| Notebook | 使用时机 |
|---|---|
| [evaluate_apps.ipynb](evaluate_apps.ipynb) | 新建业务评测，准备计划、执行和汇总 |
| [review_and_rerun.ipynb](review_and_rerun.ipynb) | 已有本地记录需要复核、用量整理或精准重测 |
| [human_comparison.ipynb](human_comparison.ipynb) | 收集独立人工对照数据 |
| [public_dataset_validation.ipynb](public_dataset_validation.ipynb) | 可选：准备公开语料后验证流程 |

输出与执行计数已清空。评测和重测开关默认为关闭。展示历史结果直接看 `docs/`；本公开包不包含历史全量 `evaluation/`。
