# 扩展轮结果与产品决策建议

数据：`expanded_v7`；24道原创模拟企业题，8份材料，4种Persona，2套自建应用。192/192唯一组合完成；201次尝试，9次异常。192条复核均署名ChatGPT AI辅助证据复核。以下结论截至2026-10-09。

## 可以支撑什么决策

这是应用配置对比和风险定位的证据，不是全平台排名或上线许可。本轮在知识库查阅、报销规则、授权流程和故障处置等设定下，Coze配置呈现出更高的任务完成比例；对于高要求的资料核查需求，仍需独立复核来源。

“通过/全部完成”保留无法确定在分母中，不能称独立明确标签上的准确率。91条来源无法确定包含卡片未展开的采集限制，不等于91条错引。

## 配对观察

相同任务×Persona形成96个配对；10个因任务结论无法确定排除。其余86个：40个双方通过，42个仅Coze通过，4个双方失败，没有仅Dify通过。42个差异组合涉及14道不同题，不是42个独立产品缺陷。

Coze的4条任务失败都来自EV018的4种Persona：P2信息提交流程遗漏。即使某应用整体表现较好，也应按具体业务任务检查缺口。来源引用通过不代表任务内容完整。

## 项目自身业务价值的现有证据

- 对比范围：2套应用、4类交互需求、24道业务题、96个配对单元。
- 决策产出：42个明确差异组合（14道题）、3条明确来源错配，可定位报告和复核依据。
- 可复核性：192个完成组合都有record.json、report.md和复核记录；矩阵可回到证据。
- 效益验证：16个人工配对单元尚无有效计时；辅助复核质量尚无独立有效参考标签。不承诺效率或准确性一定提高。

模型与检索配置不同；本地材料哈希不等于远端部署自动认证；Persona未验证可代表真实用户。结果不能拆分模型/平台因果贡献，也不能推广为总体显著性结论。
