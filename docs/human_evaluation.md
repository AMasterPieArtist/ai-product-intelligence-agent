# 人工对照：下一步验证什么

目标是估计工具是否节省主动工作时间，以及辅助复核是否优于无辅助复核。允许结果无提升或变差，不能预先认定一定优于人工。

## 时间实验

沿用`notebooks/human_comparison.ipynb`和`benchmarks/HUMAN_COMPARISON.md`的16个配对单元，统一首问、配置、输出要求。两边都要完成回答、必要证据、任务/来源结论、适配说明，再停表。工具侧包括配置启动、干预、复核和报告的人工主动时间；自动等待时间与主动时间分开。安装学习成本单列。

预定human_first/agent_first交替顺序。此前已经看过题目，熟悉效应仍存在，应记录。16个单元是先导对照，不能推断所有PM或所有产品的收益。

现有脚本计算 `(人工总主动时间－辅助流程总主动时间)/人工总主动时间`，仅纳入双方已完成且计时有效的配对。报告计数及排除原因，不能把缺测填0。

## 质量实验缺少的第三组

现有`quality_comparison.json`只有gold与assisted两套标签。它能回答辅助流程与参考判断的一致性及问题识别精确率/召回率，**不能单独回答比纯人工提升多少准确性**。

需要对同一份冻结的回答、截图、原材料，保留三组互相独立的结果：

1. 参考判断：独立复核者/仲裁者按证据建立gold，不看待比较的初始标签。
2. 无辅助人工：不看Agent复核建议，保存原始判断与计时。
3. 辅助复核：允许使用工具与AI建议，保存初始判断及计时。

若资源只有一人，可做个人探索，但不能称独立盲评；避免同人对同份证据连续评两遍后把记忆收益当工具效果。

建议新增`unaided_reviewer/unaided_task/unaided_source`及每组封存时间；当前计算脚本未实现第三组增益计算，填入字段不会自动出新指标。待真实数据采集前再接入计算，不要改写已有192条结果充当gold。

两组在相同可判定样本集合上分别对gold计算precision、recall及正确判断比例；再报告百分点差值。无法确定和未复核单列，也要报告两组判定覆盖率，防止通过排除难例得到虚高比例。按任务维度看分歧，不能把同题Persona视为独立样本。若抽样富集失败案例，需注明不能代表自然问题发生率。

## 收集后的简历句式

“在N个同范围配对单元中，辅助流程人工主动耗时由H降至A，变化为X%；在M份冻结证据上，问题识别precision/recall为P/R，无辅助人工为P0/R0。”只填实测值，同时说明样本、复核方式和质量变化；若没有提升就不写提升。
