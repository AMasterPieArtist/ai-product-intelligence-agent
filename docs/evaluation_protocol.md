# 评测与复核协议

1. **执行**：浏览器是否完成了输入、提交、观察和收尾。异常可能来自页面关闭、选择器或网络，不直接归因于被测模型。
2. **规则筛查**：首答关键词、禁止表达、不确定性条件；通过不保证语义，失败也需考虑规则过严。
3. **任务复核**：资料与需求是否支持该回答；多轮后是否满足用户目标。
4. **来源复核**：文件存在、片段真实、归属正确、片段支持结论。四者不能互相替代。

工作台对材料先比对运行时SHA256。匹配才进行TXT/MD精确子串检查；PDF/DOCX需人工打开，正文无来源需看页面截图。引号片段未匹配可能是改写或排版差异，不自动判为伪造。真实片段也可能不支持回答。

`task_completion`和`source_authenticity`分别允许not_reviewed/passed/failed/inconclusive。通过或失败需复核人与证据定位。原答案、原规则和人工判断分别保留；工具不自动改写历史结果。工作台导出的review_seconds为从第一次编辑到导出的经过时间估计，可能包含思考和中断，应以相同方式测量或另用人工计时。

重测范围区分：execution_errors是执行异常；review_failed是人工确认的任务/来源失败；unreviewed表示人工尚未核对。规则failed不会自动变成人工失败。优先复核已有回答，避免因未复核而重跑。

## 数据来源

- smoke：原用户提供的项目材料；验证浏览器路径与基础事实。
- business_v1/v2：本项目编写的模拟业务材料；用于受控条件，不称真实客户案例。
- DuReader-robust：官方公开语料5题，目的性筛选，开发集不是企业需求测试集。参考答案逐条是原文子串，但语料可能有年代或事实问题；按给定资料问答。

现有字符F1和整段EM是本地词面诊断，不是官方DuReader指标；含解释/来源的长答会影响数值。5题不是完整基准，不能估计通用正确率或代表平台能力。

同范围人工基线至少记录：资料阅读、手工提问、追问、证据整理、复核与报告的时间。自动方案总成本也必须包含配置、运行、排错和复核。没有基线时，记录原始耗时与用量，不填写提升百分比。

## 当前扩展轮与复核署名

expanded_v7为24题×4Persona×2应用，8份原创模拟材料；全部192条复核署名ChatGPT AI辅助证据复核。目录名human_reviews是存储字段，不证明独立人工参与。状态未知与未复核保留，不并入失败或通过。每题四种Persona不当作四位独立真实用户。

欲测量相对无辅助人工的准确性增益，需为同一份冻结证据增加无辅助人工标签，并与独立gold分别比较；当前compare_metrics的gold/assisted两列不足以给出此增益。详见human_evaluation.md。
