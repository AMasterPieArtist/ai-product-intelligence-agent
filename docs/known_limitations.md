# 已知限制与后续工作

[结果分析](reports/results_analysis.md) · [评测协议](evaluation_protocol.md)

| 范围 | 当前状态 | 对使用结论的影响 |
|---|---|---|
| 产品接入 | 已验证两套具体网页；其他产品需要 Adapter | 打开 URL 不等于完成自动评测接入 |
| 来源采集 | Dify 来源卡片采集文件名，未展开原文 | 无法确定不能当作来源错误，也不能判通过 |
| 应用配置 | 两边模型、检索和提示词不完全相同 | 比较当前应用配置，不推导平台因果优劣 |
| Dify 回答缺口 | 部分回答遗漏材料已有条款；未完成后台链路定位 | 是待排查的应用表现，不能直接认定网络故障或平台能力差 |
| Persona | 四种有界行为策略，最多一次追问 | 不是独立真实用户或完整用户研究 |
| 复核 | 历史扩展轮使用 AI 辅助证据复核 | 不作为独立人工金标准或已验证的自动裁判准确率 |
| 人工收益 | 16 个配对单元尚无有效数据 | 不报告节省时间或准确性提升 |
| 网页稳定性 | DOM 定位与结束信号依赖当前页面 | 页面更新后需小规模检查，有限重试不能保证网络稳定 |

当前重点是让场景判断有证据、让缺口可定位。后续可开展真实 PM 使用测试、补齐来源卡片采集、进行人工对照，或接入第三套应用。项目尚未验证上线规模、商业收益或生产可用性。
